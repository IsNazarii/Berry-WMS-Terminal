# Berry WMS Terminal

Термінал приймальника ягід: прийом, зважування, розподіл по фурах і розрахунок
з постачальниками. Працює офлайн — усі операції записуються локально й
синхронізуються з сервером, коли з'являється зв'язок.

Навчальний проєкт з курсу «Основи ООП» (2025–2026).

## Структура

| Каталог | Зміст |
|---|---|
| `core/` | доменна модель на чистому C++20 (без Qt) |
| `app/`  | точка входу `main()` |
| `tests/` | unit-тести (GoogleTest) |
| `docs/` | документація, вимоги, звіти |

## Збірка

Потрібні: CMake ≥ 3.28, компілятор з підтримкою C++20 (GCC 13+), Ninja.

```bash
cmake -S . -B build -G Ninja
cmake --build build
ctest --test-dir build --output-on-failure
./build/app/wms_terminal
```
