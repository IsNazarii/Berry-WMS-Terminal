# Навчальний курс

Berry WMS Terminal — особистий проєкт автора для реального пункту прийому ягід. Восени 2026 року він водночас
був соло-проєктом курсу «Основи ООП»: три лабораторні та фінальний реліз. Усе, що стосується курсу, зібрано тут.
Решта документації описує сам термінал.

## Етапи

| Дата | Етап | Що здано |
|---|---|---|
| 25.09.2026 | Лаба 1: ООП-ядро | доменна модель на C++20: класи, ієрархії, поліморфізм, інкапсуляція, unit-тести |
| 23.10.2026 | Лаба 2: GUI | шість екранів на Qt 6 / QML, власний стиль, стан і довідники в SQLite |
| 13.11.2026 | Лаба 3: зовнішня бібліотека, реліз | друк чека з QR-кодом ([nayuki QR-Code-generator](https://github.com/nayuki/QR-Code-generator)), звіт |

Усі етапи закрито. Після курсу проєкт розвивається як звичайний продукт ([дорожня карта](../../README.md#дорожня-карта)).

## Що курс залишив у проєкті

- **Малі кроки:** кожна зміна є окремим комітом зі змістовним повідомленням, тож історію в `git log` легко читати.
- **Тест-першим для ядра** і unit-тести на GoogleTest.
- **Декларація використання ШІ** ([README](../../README.md#використання-ші)): автор розуміє весь код, асистент пояснює
  нетривіальні рішення.
