# Berry WMS Terminal

Термінал приймальника ягід: прийом, зважування, розподіл по фурах і розрахунок
з постачальниками. Працює офлайн — усі операції записуються локально й
синхронізуються з сервером, коли з'являється зв'язок.

Навчальний проєкт з курсу «Основи ООП» (2025–2026).

## Що вже вміє ядро

- Чек постачальника з кількох зважувань (палет), різних культур; нетто = брутто − тара ящиків − палета.
- Два режими розрахунку: роздріб (ціна відома, виплата одразу або пізніше — борг у журналі)
  та опт (лише вага, розрахунок робить відповідальна особа).
- Розподіл по фурах: цілою палетою або певною кількістю ящиків культури; заповненість фури
  за ящиками та/або кілограмами, переповнення позначається, а не блокується.
- Прийом лише стабільної ваги (симулятор ваг + детектор стабільності).
- Гроші й вага — цілі числа (копійки, грами); ID записів — UUIDv7 для офлайн-синхронізації.

## Збірка

Потрібні: CMake ≥ 3.28, компілятор з підтримкою C++20 (GCC 13+), Ninja.

```bash
cmake -S . -B build -G Ninja
cmake --build build
ctest --test-dir build --output-on-failure
./build/app/wms_terminal
```
